## 5. Configuration and decisions

1. **Production URL**: `site` defaults to the placeholder `https://va-capability.example.com`. Set `SITE_URL` at build time so canonical, OG and sitemap URLs are correct.
2. **Indexing**: `noindex` is **on** by default (client-share document). Set `PUBLIC_NOINDEX=false` to allow indexing.
3. **Contact form**: there is none. `/contact/` is a directory with `tel:` and `mailto:`. A form needs an endpoint, a privacy notice and a CRM destination.
4. **Privacy link** points to `https://www.colliers.com/en-au/privacy-policy`. Confirm the correct URL.
5. **Header height**: the brief asks for 88 → 64 px. Condensed is **72 px**, because the 96 px minimum logo width is 55 px tall and 64 px would break the 2× colour-bar clear-space rule.
6. **`inspiration.md`** was not supplied. Direction followed brief §4.
7. **Example deck** was supplied as PDF (not PPTX). Images were extracted from the PDF. No `ppt/media/` originals exist, so they are lower resolution than the source PPTX would be.
